#### Почему Playwright, а не Selenium?

Скорость: Тесты работают в 2-3 раза быстрее

Встроенные фичи: Ожидания, моки сети, мобильная эмуляция и тд.

Тренд: 70% новых проектов выбирают Playwright (данные 2024)
